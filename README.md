# Central da Fábrica 3D

ERP interno da marca Y2K de objetos impressos em 3D: estoque de filamentos, produtos com custo automático, produção, pedidos, logística, financeiro com acerto de contas entre sócios, relatórios, tarefas, quadro de posts e chat da equipe.

- `app/index.html`: o app (fonte única)
- `hostinger/`: o pacote do servidor (PHP 8.2 + MySQL), com instalador
- Instalação: `hostinger/LEIAME.md` · GitHub → Hostinger: `GITHUB-E-HOSTINGER.md`
- Segurança: `hostinger/SEGURANCA.md` · Contexto para IA: `CLAUDE.md` · Histórico: `HISTORICO.md`
